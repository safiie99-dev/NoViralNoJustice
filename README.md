# NoViralNoJustice
Dataset of research on #NoVIralNoJustice phenomena in Indonesia.
The data was scraped through YouTube Data API that contains: Video Description and each video's comments   
High-profile case of:
1. Ferdy Sambo
2. Mario Dandy
3. Kopi Sianida
4. Vina Cirebon

Folder info contains several video information scraped through YouTube Data API
File ferdy_sambo.zip contains comments on Ferdy Sambo's video case 
File kopi_sianida.zip contains comments on Kopi Sianida's video case
File mario_dandy.zip contains comments on Mario Dandy's video case
File vina_cirebon.zip contains comments on Vina Cirebon's video case
